GitHub Authentication

Because your website is hosted on GitHub, you need to provide a GitHub Access Token to update the menu database.

How to get your token:
  1. Go to GitHub Fine-grained Tokens
  2. Click Generate new token
  3. Name it "Bhukad Hut Admin"
  4. Under Repository Access, select "Only select repositories" and pick `bhukad-hut`
  5. Under Permissions -> Repository Permissions, find Contents and change it to Read and write
  6. Click Generate at the bottom, and paste the code here!
